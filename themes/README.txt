THEMES

DejaVuAmp comes with six colour themes: Dreamspace (the default), ANSI 16 colors, Phosphor green, Amber monochrome, Paper (light)
and High contrast. Pick one in the Options panel.

To add your own, put a theme file in this folder (*.dva-theme.json), a small JSON file with "dva-theme": 1, a name and the colours. Colours that are hard to read against the background are refused. New files show up in the theme list within a couple of seconds.
