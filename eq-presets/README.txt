EQUALIZER PRESETS

Your own equalizer presets are files in this folder (*.dva-eq.json). The "Export" button in the equalizer writes one here; a file that someone
sent you works when you put it in this folder. They show up in the preset list within a couple of seconds. Take a file out to remove the preset.
The same files work in the web version of DejaVuAmp.

Classic equalizer libraries (*.eqf, the kind other players export) also work: drop one in this folder and every preset inside it appears in the list under
"From files". Only the preset names, ten band values and the preamp are used.
